# Cuervo Maestro

El Cuervo Maestro preside el [Pequeño Consejo](pequeno-consejo-de-los-cuervos-grises.md)
de los Cuervos Grises. Cuando sus integrantes no alcanzan un acuerdo en una
deliberación, decide el Maestro.

En tiempos de Iyuri Khan, el Maestro intervino para detener la maniobra con que
el Consultor pretendía reclutarlo mediante Bendji Zharan.
