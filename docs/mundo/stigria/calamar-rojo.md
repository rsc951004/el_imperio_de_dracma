# Calamar Rojo

El nombre identifica dos elementos distintos:

- **Antigua banda adolescente:** banda de saqueadores de Sturmgard cuyo
  capitán fue Iyuri Khan durante su adolescencia.
- **Barco de Iyuri:** embarcación capitaneada por Iyuri en su viaje con
  Rendard Steinert.

El motivo por el que Iyuri reutilizó el nombre para el barco no está
establecido.
